User Management REST API (Node.js & Express)

This project is a simple RESTful API for managing user records, built using Node.js, Express.js, and custom middleware.
It supports creating, updating, deleting, and fetching user data, along with request logging and validation of user input.

🚀 Features--

Create new users (POST)

Update existing users (PUT)

Fetch all users or a single user by ID (GET)

Delete users (DELETE)

Validation middleware for:

Required fields

Email format check

Duplicate email prevention

Request logging middleware to track request duration and status

In-memory user storage (no database required)
